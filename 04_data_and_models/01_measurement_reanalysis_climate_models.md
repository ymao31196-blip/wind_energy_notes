# 观测、再分析与气候模式

风电与气候研究中经常同时使用观测、ERA5和CMIP6气候模式。三者都可以给出风速，却来自不同的数据生成机制。理解它们的角色差异，是后续比较、校正和机器学习建模的基础。

## 1. 现场观测

现场观测最直接地记录某个地点、某个高度和某段时间的大气状态。

它的优势是：

- 地点真实；
- 可用于设备和模型验证；
- 可以保留高时间分辨率变化。

局限是：

- 空间覆盖有限；
- 时间长度可能不够；
- 缺测、设备变化和环境变化需要质量控制；
- 单点观测未必能代表复杂区域。

工程分析常将现场观测作为参考，但仍需考虑仪器误差、数据质量和空间代表性。

## 2. 再分析资料

再分析（reanalysis）由数值天气模式、数据同化系统和历史观测共同构成。

数据同化可以理解为按照观测误差和模式误差，把卫星、地面站、探空等不完整观测与数值模式给出的背景场进行融合。再分析通过固定或相对统一的数值天气模式与数据同化系统，把大量历史观测整合成时间连续、空间完整的大气状态估计。因而ERA5中的格点值应理解为观测约束下的模式估计，和单台仪器在某个位置直接记录的原始观测属于不同数据形态。

ERA5是ECMWF第五代全球再分析。ECMWF公开资料指出，ERA5覆盖1940年至今，提供大量大气、陆面和海洋变量的逐小时估计，原生大气网格约31 km，并提供10 m风分量等变量。

ERA5同时具有两个特征：

1. 它“受观测约束”；
2. 它同时“受数值模式和同化系统约束”。

ERA5常用于历史背景、参考资料和模型评估；具体使用时仍需考虑变量、空间尺度和再分析自身的不确定性。

## 3. 气候模式

气候模式的任务和再分析不同。

像CanESM5（Canadian Earth System Model version 5）这样的地球系统模式用于模拟气候系统本身的演化。CMIP6（Coupled Model Intercomparison Project Phase 6）把多个机构的气候模式实验组织在统一协议下，便于比较历史模拟和未来情景。单个模式的一次运行可以看作在给定外部强迫和初始条件下产生的一条气候实现，它不要求逐日逐月复现现实世界发生过的同一串天气过程。

CanESM5可以：

- 模拟历史气候；
- 研究内部变率；
- 在给定排放和社会经济情景下进行长期未来投影。

CanESM5的模型论文明确指出，它面向历史气候变化与变率、百年尺度未来气候投影，以及季节—年代际预测等任务，并参与CMIP6。

气候模式在给定边界和强迫条件下生成物理自洽的气候轨迹，重点描述气候统计特征、内部变率和情景响应。即使外部强迫相同，轻微不同的初始条件也可能产生不同的天气序列，这部分差异属于内部变率；因此气候模式更常在长期统计量、分布和趋势层面与观测或再分析比较。

## 4. SSP585情景

SSP（Shared Socioeconomic Pathways，共享社会经济路径）情景通过CMIP6的ScenarioMIP实验与排放、辐射强迫条件结合，用于构造未来气候模拟。数据文件中常把SSP5-8.5写作`ssp585`，本仓库沿用SSP585这一简写。

SSP585是其中一个高强迫情景。其时间序列表示该情景下的一条气候模拟轨迹：

> SSP585中的2050年7月表示该情景轨迹中的一个模拟月份，不提供现实世界同月天气的确定性预测。

它代表该情景下某个可能的气候演化轨迹。

因此，即使现实世界到了2050年并有ERA5，也不能把现实ERA5的2050年7月与SSP585模拟的2050年7月逐月一一对应为“预测—真值”。

## 5. CanESM5与ERA5的差异来源

差异可能来自：

- 空间分辨率不同；
- 模型物理过程与参数化不同；
- 地形和下垫面表达不同；
- 内部气候变率不同；
- 数据同化：ERA5受真实观测约束，自由运行气候模式通常不进行同类的观测同化；
- 变量和时间平均方式不同。

CanESM5→ERA5同时涉及空间尺度转换和资料系统差异，复杂度明显高于普通图像分辨率提升。

它同时混合了：

```math
\text{空间尺度差异}
+
\text{资料系统偏差}
+
\text{不同气候轨迹}.
```

气候模式风场精细化需要同时处理分辨率差异、系统偏差和情景状态保持。

## 6. 历史参考的作用边界

历史期可以将ERA5作为高分辨率、受观测约束的监督参考。

但如果训练目标只是“尽可能变得像ERA5”，模型有可能同时改写气候模式原本携带的均值、变率和极端结构。

面向未来情景时，模型目标需要同时明确两个维度：历史参考恢复程度，以及对气候模式情景信息的保留程度。两者的权重取决于具体研究目的。
