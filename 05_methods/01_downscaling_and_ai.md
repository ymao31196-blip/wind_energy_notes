# 降尺度、精细化与AI

当全球模式、再分析或中尺度模型的空间分辨率不足以直接描述目标区域时，就会遇到“如何从粗尺度信息得到更细尺度信息”的问题。统计降尺度、动力降尺度和AI精细化都是在回答这个问题，但它们解决问题的方式不同。

## 1. 降尺度问题

粗尺度变量记为$`X_c`$，细尺度变量记为$`Y_f`$，降尺度试图寻找某种映射

```math
Y_f=F(X_c,Z),
```

其中$`Z`$可以是高分辨率地形、土地利用、历史观测、时间特征或其他辅助信息。

这个表达把复杂性集中到了$`F`$：

- 它依据物理方程还是统计关系？
- 历史关系在未来是否仍成立？
- 高分辨率细节是输入中真实存在的，还是模型“生成”的？
- 模型输出的均值和方差是否被改变？
- 极端事件是否被削弱？

## 2. 动力降尺度

动力降尺度使用区域数值模式，例如WRF，以大尺度模式或再分析作为初始/边界条件，通过更细网格和更丰富的区域物理过程生成区域气候。

优点：

- 物理过程表达完整；
- 可以同时得到多个气象变量；
- 地形和陆面过程能更细致地进入模型。

代价：

- 计算成本高；
- 结果依赖物理参数化、边界条件和网格配置；
- 高分辨率不自动等于高准确度。

## 3. 统计降尺度

统计降尺度从历史数据中学习大尺度变量和局地变量之间的关系。

例如：

```math
Y_{local}=a+bX_{large}+\varepsilon.
```

也可以使用更复杂的广义线性模型、树模型、随机森林、神经网络等。

优点是计算成本低、部署方便，但核心假设是历史期学到的关系具有一定迁移性。气候变化场景下，这个假设必须被检查。

## 4. AI精细化与图像超分辨率的差异

从张量形状看，二维风场与图像数据相似，这使CNN、U-Net、Transformer等模型能够直接用于风场细化。

风场虽然在张量形式上类似图像，但还受到物理变量关系和时空统计结构的约束。

至少存在四个额外要求：

1. $`u,v`$之间有矢量关系；
2. 输出需要维持合理的空间连续结构；
3. 均值、方差、尾部和时间变化都有物理含义；
4. 面向未来时，模型不能只会把所有输入拉回历史参考分布。

风场精细化的评价需要覆盖物理变量关系和时空统计结构，视觉清晰度本身不足以说明结果质量。

## 5. 参考恢复与状态保持

假设历史期有粗模式场$`B`$和高分辨率参考场$`R`$。

直接监督时常见的目标是

```math
\min \|F(B)-R\|.
```

这会鼓励输出接近历史参考。

但如果未来应用依赖$`B`$中的气候情景信息，就可能还要控制

```math
\text{state}(F(B))
\approx
\text{state}(B),
```

其中$`state`$可以表示区域均值、变率、高分位、长期趋势等统计结构。

由此形成参考恢复与状态保持之间的多目标权衡：

```math
\text{Reference Recovery}
\quad\leftrightarrow\quad
\text{State Preservation}.
```

实际模型中，强参考校正可能减少历史误差，同时压缩原模式的振幅和尾部，这种张力可以在验证集和独立测试中直接检查。

## 6. 残差参数化

残差参数化可以把输出写成主体场与修正量之和：

```math
Y=B+\lambda\Delta.
```

$`B`$作为主体场，$`\Delta`$是模型学习到的修正，$`\lambda`$控制修正强度。

$`\lambda`$直接控制修正强度。$`\lambda=0`$时保留原场，随着$`\lambda`$增加，参考校正逐步增强，可以在验证集上显式研究参考恢复与主体保持之间的变化。

## 7. RMSE的评价边界

RMSE回答的是“平均误差有多大”，但未必能回答：

- 方差是否被压缩？
- 高风尾部是否消失？
- 季节循环是否改变？
- 未来输入是否超出训练分布？
- 下游风电指标是否发生不合理变化？

AI风场评价通常需要组合多层证据，单一分数很难覆盖不同目标。

常见的补充包括：

- Bias、MAE、相关系数；
- 区域均值和标准差；
- 分位数与极端事件；
- 季节循环和趋势；
- 空间结构指标；
- 分布外诊断；
- 功率或CF等下游指标。

## 8. 相关开源项目

目前较有代表性的开源项目包括：

- Predicting the Wind：从场景问题出发，把测量、长期风估计和发电输出串在一起；
- Pywind：按真实风数据分析任务组织Notebook；
- OpenOA：把风电场运行数据结构、质量控制、功率曲线和AEP等方法做成可复现框架；
- awesome-wind：用社区索引连接风资源、尾流和仿真工具。

这些项目普遍围绕实际任务组织数据、代码和评价流程，这种结构与本仓库的组织方式一致。

一个模型即使取得最低历史RMSE，如果同时明显压缩原气候模式的方差，其未来迁移价值仍需结合任务目标判断。下一篇案例具体讨论参考恢复与状态保持之间的权衡。
