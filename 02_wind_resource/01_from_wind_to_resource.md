# 从“有风”到“风资源”

“这里风很大”只能描述某个时刻或一段时间的感受。风资源评估需要进一步判断目标高度和区域内的长期统计特征、空间代表性，以及这些风经过风机特性转换后能够形成怎样的能源产出。

## 1. 风速只是起点

最基本的风速可以由水平风分量得到：

```math
ws=\sqrt{u^2+v^2}.
```

气象学通常用$`u`$和$`v`$表示两个水平风分量，风速模长则常写为$`V`$或$`ws`$。在常用地理坐标中，$`u>0`$表示向东的分量，$`v>0`$表示向北的分量；它们描述空气实际运动方向，与“风从哪里来”的气象风向定义需要区分。本仓库统一用$`ws`$表示风速，避免变量符号混淆。

ECMWF对ERA5的说明中明确给出了

```math
|\mathbf V|=\sqrt{u^2+v^2}.
```

但需要区分“瞬时分量合成的风速”和“先对分量求时间平均、再合成得到的风速”。由于平方根是非线性运算，两者通常并不相同。这一点在月平均数据进入风电功率计算时尤其重要。

## 2. 平均风速的局限

同样的年平均风速，可能对应完全不同的风况。

例如两个地点的年平均风速都为7 m/s：

- 地点A大多数时间稳定在6–8 m/s；
- 地点B很多时间几乎无风，但偶尔出现很强的风。

这两个地点对于风机发电、结构载荷和电网波动的意义都不同。风资源评估通常还需要风速概率分布、分位数、方向频率、湍流强度和时间变化。

风速分布常用Weibull分布近似描述。NREL的风资源评估案例中也使用Weibull的形状参数$`k`$与尺度参数$`c`$来概括风速分布。$`k`$是无量纲形状参数，控制分布的宽窄和偏斜程度；$`c`$具有风速单位，控制分布的整体尺度。相同平均风速下，不同$`k`$仍可能对应不同的低风和高风出现频率。但Weibull是一种常用统计模型，不意味着所有地点的真实风速都严格服从Weibull分布。

## 3. 高度与风切变

近地层中，地表摩擦使风速随高度发生明显变化。工程中常通过测风塔、激光雷达或模型得到不同高度风速，并分析风切变。

最简单的幂律表达为

```math
\frac{V(z)}{V(z_r)}
=
\left(\frac{z}{z_r}\right)^\alpha,
```

其中$`z_r`$是已知风速的参考高度，$`z`$是目标高度，$`\alpha`$是风切变指数；两个高度应采用相同的高度基准和单位。这个关系常用于把测量高度的风速近似外推到轮毂高度。

这个公式用于直观近似。$`\alpha`$会随大气稳定度、粗糙度、地形和天气条件变化，实际评估需要根据场址条件确定风切变参数。

## 4. 风向与来流条件

风向决定了空气从哪个方向进入场址，也决定了：

- 上游是什么地形和地表类型；
- 风机之间如何形成尾流；
- 山脊、谷地和建筑物如何影响局地流动；
- 一个测量点能否代表目标区域。

气象风向采用“风从哪里来”的定义。ECMWF给出的约定是：北风0°、东风90°、南风180°、西风270°。这个定义和通常数学极坐标角度的方向并不相同，从$`u,v`$计算风向时不能直接套普通的$`\arctan(v/u)`$。

## 5. 空间上的风资源

风资源具有明显的空间结构。地形越复杂，附近位置之间的风速差异越可能显著。

Global Wind Atlas的方法体现了一个典型思路：

```math
\text{大尺度再分析}
\rightarrow
\text{WRF中尺度模拟}
\rightarrow
\text{微尺度局地化}.
```

其当前公开方法使用ERA5作为大尺度背景，WRF生成约3 km中尺度场，再通过风图谱微尺度方法得到更高分辨率的风资源描述。这个流程清楚区分了各尺度的任务和信息传递关系。

## 6. 时间上的风资源

长期风资源至少包含四种常见变化：

1. 日变化：海陆风、山谷风和边界层日循环；
2. 季节变化：冬夏环流和季风变化；
3. 年际变化：不同年份大尺度环流背景不同；
4. 长期变化：气候变化或年代际变率。

一两个月的强风不足以代表长期风资源。工程评估通常把有限现场测量与更长时间的参考资料结合，Measure-Correlate-Predict（MCP）就是其中一种常见长期订正方法：先在两套资料重叠的时间段建立统计关系，再把该关系用于更长的参考序列。

两个地点即使具有完全相同的平均风速，只要风速分布的离散程度不同，平均发电能力也可能不同。原因将在下一部分结合风机功率曲线继续展开。
