# 案例：CanESM5—ERA5风场精细化中的“参考恢复—主体保持”权衡

这个案例来自作者当前的风场精细化重跑与小论文工作，涉及气候模式、再分析资料、AI精细化、多目标评价，以及风速到风电指标的非线性传导。

## 1. 研究问题

CanESM5是参与CMIP6的地球系统模式，这里提供连续的历史风场和SSP585未来情景风场；ERA5则是由数值天气模式和历史观测同化形成的再分析资料。二者都能给出近地层风场，但数据生成机制不同：CanESM5强调气候统计、内部变率和情景响应，ERA5强调对历史实际大气状态的连续重建。当前任务中CanESM5空间分辨率较粗，ERA5具有更高空间分辨率并受到历史观测约束。

历史期可以以ERA5作为监督参考。训练前先把CanESM5与ERA5的时间、变量定义和空间范围对齐，使同一个历史月份的粗分辨率模式风场与高分辨率参考风场形成对应样本，再构造下面的精细化映射：

```math
\text{CanESM5}
\rightarrow
\text{AI refinement}
\rightarrow
\text{ERA5-like high-resolution field}.
```

在历史重建任务中，这一目标具有明确意义。

未来迁移阶段没有与SSP585轨迹逐月对应的ERA5“真值”。如果历史训练过度拉近CanESM5与ERA5的统计分布，未来输出中的CanESM5均值、变率和高分位结构也可能被压缩。本案例同时考察ERA5历史参考恢复与CanESM5主体状态保持。

## 2. 三个比较对象

当前冻结的小论文主线使用三个对象。

### B：主体基线

B是不进行模型校正的CanESM5主体基线。可以把它理解为“如果完全不做AI修正，原始模式场是什么样”，后续所有参考恢复和主体保持指标都以它作为共同基准。

### M1：参考恢复路线

M1直接学习CanESM5到ERA5的映射，重点降低历史期相对ERA5的误差。

### M2：受控残差路线

M2以B作为主体场，并叠加网络预测的残差修正：

```math
Y_{M2}=B+\lambda\Delta.
```

当前最终冻结版本中

```math
\lambda=0.30,
```

并且只由验证集选择。独立测试集不参与$`\lambda`$选择。

这个版本最终**不使用MOMENT时序条件**。这里的MOMENT用于从连续12个月序列提取时序表征，再用PCA压缩到16维后输入模型。纠偏后的MOMENT-PCA16实验经过三个随机种子测试后，没有观察到稳定增量收益，最终关闭该条件。这个结论只针对当前月尺度任务，不推广为“时序信息无效”。

## 3. 数据切分

历史有效月份为1979-12至2014-12，共421个月。

按时间顺序划分。训练集用于拟合模型参数，验证集用于选择$`\lambda`$等超参数和比较候选方案，独立测试集只在这些选择冻结后用于最终评价：

| 集合 | 月数 |
|---|---:|
| 训练 | 294 |
| 验证 | 63 |
| 独立测试 | 64 |

独立测试期为2009-09至2014-12。

这一划分避免随机打乱时间序列后带来的时间泄漏，也保证$`\lambda`$和模型选择不使用测试集信息。

## 4. 历史参考恢复

未来SSP585没有逐月对应的参考真值，因此模型是否学到了稳定的历史映射，只能在仍然存在ERA5参考的历史独立测试期检验。这里的历史评价用于验证方法在未参与训练的历史月份上能否恢复参考结构，同时检查是否过度改写CanESM5主体状态；它不能直接证明未来情景输出的准确度。

以ERA5为参考，在独立测试期计算风速代理

```math
ws=\sqrt{u^2+v^2}.
```

三种方法的ws RMSE如下。RMSE与风速具有相同单位，数值越低表示在这一参考定义下与ERA5的平均平方误差越小：

| 方法 | ws RMSE (m/s) |
|---|---:|
| B | 1.1311 |
| M1 | **0.7119** |
| M2 | 0.9003 |

独立测试结果显示，M1的ERA5历史参考恢复能力最好。

M2的历史参考恢复没有超过M1，现有结果不支持“精度最优”的表述。

## 5. 主体保持

再以B为参照，比较输出相对CanESM5主体的统计量保持。

这里的std表示标准差，用于描述风速序列的波动幅度；p95表示95%分位数，也就是约95%的样本不超过该值，用来检查较高风速尾部是否被明显压缩。保持比等于1表示与B相同，小于1表示相应统计量被压缩，大于1则表示被放大。

| 方法 | 均值保持比 | std保持比 | p95保持比 |
|---|---:|---:|---:|
| B | 1.0000 | 1.0000 | 1.0000 |
| M1 | 0.6339 | 0.7650 | 0.7433 |
| M2 | **0.8363** | **0.8932** | **0.8901** |

M2在这三项指标上明显比M1接近B。

“更接近B”表示对CanESM5主体统计结构的改写较少，用于衡量状态保持程度；它不提供与真实世界接近程度的直接证据。

## 6. 双目标约束

定义相对B的历史参考改善率。式中$`E_m`$表示候选方法相对ERA5的参考误差，$`E_B`$表示B的参考误差。若$`A=0`$，表示相对B没有改善；$`A>0`$表示误差下降，$`A<0`$表示误差反而增大：

```math
A=1-\frac{E_m}{E_B},
```

为描述三个统计保持比整体有多接近1，定义主体保持得分$`P`$。其中$`r_q`$依次代表均值、标准差和p95保持比。当三个保持比都等于1时$`P=1`$；偏离1越多，$`P`$越低：

```math
P
=
\exp\left[
-\frac{1}{3}
\sum_{q\in\{mean,std,p95\}}
|\log r_q|
\right].
```

同时定义用于硬约束判断的最低主体保持率

```math
R_{min}
=
\min(r_{mean},r_{std},r_{p95}).
```

在当前设定的政策情景

```math
A\ge0.15,
\qquad
R_{min}\ge0.80
```

下：

- B没有参考改善；
- M1主体保持不足；
- M2同时满足两个最低要求。

在当前阈值条件下，M2是**唯一可行候选**。

这里的“评价政策”指人为设定的筛选阈值规则，用来明确研究者愿意接受的最低参考改善和最低主体保持水平，不对应现实法规或行业强制标准。0.15和0.80只服务于当前比较；主体保持下限提高到0.85，或参考改善下限提高到0.25时，M2都会失去可行性。

## 7. Pareto关系与结论边界

当前B、M1、M2在$`(A,P)`$空间中都是Pareto非支配点。所谓“非支配”，是指不存在另一个方案能够在一个目标不变差的同时，让另一个目标严格变好；因此三者代表不同的参考恢复—主体保持取舍。

三种方法之间不存在同时改善两个目标的支配关系。

进一步看，如果把参考改善与主体保持按算术等权方式合成一个比较效用，M2相对M1的效用差只有

```math
-0.002754,
```

为了判断这个很小的差值是否稳定，使用12个月循环移动块Bootstrap：以连续12个月为重采样单元，尽量保留月序列中的短期相关性，再重复计算效用差。得到的95%区间为

```math
[-0.023832,\ 0.018703],
```

区间跨过0。

当前证据将M2限定为指定最低约束下的可行折中。现有结果不足以支持“M2整体最优”的结论。

多目标评价的价值在于把不同目标及其取舍显式列出，避免用单一综合分数掩盖任务偏好。

## 8. SSP585结构迁移

2015—2100年的SSP585未来迁移中：

| 方法 | 平均ws | std | p95 |
|---|---:|---:|---:|
| B | 1.7131 | 0.6322 | 2.8208 |
| M1 | 1.1519 | 0.2261 | 1.5496 |
| M2 | 1.4553 | 0.4927 | 2.2940 |

M1相对B出现更强的幅度压缩，M2保留更多B的均值、变率和高分位量级。

由于未来阶段没有与SSP585情景轨迹匹配的真值，这些结果用于描述M1和M2对未来情景场的作用方式，不用于判断哪一种方法未来更准确。

## 9. 风电代理传导

案例进一步把风速通过简化功率曲线映射为容量因子（Capacity Factor, CF）代理。这里的“代理”表示统一转换规则下的相对出力指标，用来观察上游风场差异怎样经过非线性功率曲线传到下游；它不等同于真实风电场基于轮毂高度风况、机型、尾流和运行损失得到的工程CF。

输入仅包含月平均近地层$`u,v`$，缺少轮毂高度修正、高频风速分布、尾流、机组可利用率和限电等信息。这些数值只作为CF代理使用。

该代理用于检查上游风场处理差异能否传导到下游风电指标。

当前结果还发现：先逐格点施加非线性功率曲线再空间聚合，与先空间平均风速再施加功率曲线，结果可以相差多个数量级。

这种差异对应非线性映射中的

```math
\mathbb E[f(X)]\neq f(\mathbb E[X]),
```

说明统计聚合顺序本身会改变风电代理结果。

## 10. 从这个案例保留下来的经验

从当前重跑中可以保留四点方法经验：

1. 区分“历史参考恢复”和“原模式状态保持”；
2. 测试集不参与超参数和残差强度选择；
3. 面向未来情景时，不伪造不存在的未来真值；
4. 下游代理指标必须明确它不等于真实工程量。

这些原则可以继续迁移到WRF、多源融合、CFD代理和其他风资源AI任务中。

## 案例事实边界

当前案例来自已冻结的最终事实源。需要保留以下限制：

- 仅使用单一CanESM5模式和SSP585情景；
- 历史独立测试仅64个月；
- 45×57操作网格的原始坐标身份尚未完全恢复，不做确定性逐点地理解释；
- SSP585未来没有情景对应真值；
- CF只作为简化代理，不代表真实发电量；
- 不能据此证明真实能源规划收益。
