# SCADA、运行监测与性能诊断

风机投运后会持续产生运行数据。SCADA（Supervisory Control and Data Acquisition，监控与数据采集系统）把风速、功率、转速、桨距、温度、状态码等变量记录下来，使风电研究从“资源和设计阶段”延伸到真实运行阶段。SCADA主要承担监视、记录和上层控制接口作用，不等同于变流器或变桨系统内部毫秒级执行的底层控制回路。

## 1. SCADA中有什么

具体变量取决于机型和厂商，常见类别包括：

- 环境与来流：机舱风速、风向、环境温度；
- 气动与控制：桨距角、偏航状态；
- 机械系统：转子/发电机转速、轴承和齿轮箱温度；
- 电气系统：有功功率、无功功率、电流、电压；
- 运行状态：启停、故障码、限功率状态；
- 子系统温度与报警。

Pandit等（2023）的综述指出，研究中最常见的是10 min聚合SCADA数据。这里的“10 min数据”通常表示把更高频的原始信号在每10 min窗口内汇总成均值、最小值、最大值、标准差等统计量，并不意味着传感器每10 min才测一次。高频数据可以保留更多动态信息，但会显著增加存储和计算负担。

## 2. SCADA与高频状态监测的区别

10 min SCADA常用于长期运行趋势、功率性能和部分异常检测。

齿轮箱振动、结构振动、电流波形、应变和声学信号通常需要更高采样率。专用Condition Monitoring System（CMS）会提供SCADA难以保留的高频故障信息。

两类数据的关系可以概括为：

```math
\text{SCADA}
\rightarrow
\text{长期、低频、全机组运行状态},
```

```math
\text{CMS}
\rightarrow
\text{局部、高频、部件健康信息}.
```

实际诊断可以组合两类数据。

## 3. 性能监测

性能监测关心机组是否在给定环境条件下产生预期功率。

最基础的做法是比较实测功率与参考功率曲线。实际分析还需要排除或单独标记：

- 停机；
- 限功率；
- 结冰；
- 尾流影响；
- 异常偏航；
- 传感器故障；
- 维护时段。

如果直接把这些状态混在一起拟合功率曲线，模型可能把控制行为或故障状态解释成正常气动关系。

## 4. 正常行为模型

SCADA状态监测中常建立Normal Behaviour Model（NBM）。模型使用健康时段的数据学习正常输入—输出关系，例如

```math
\hat T_{bearing}
=
f(
P,
\omega,
T_{ambient},
\ldots
).
```

当实际轴承温度持续偏离预测值时，残差

```math
r_t
=
T_{bearing,t}
-
\hat T_{bearing,t}
```

可能成为异常指标。若$`r_t`$持续为正，表示实际温度长期高于模型根据当前工况预测的正常温度；单个时刻的残差很大通常不足以直接判定故障，还需要结合持续时间、阈值和其他变量。

NBM可以采用线性模型、随机森林、神经网络、支持向量机或概率模型。模型形式只是诊断链的一部分，健康基线选择、数据清洗和误报控制同样重要。

## 5. 故障检测与剩余寿命

运行维护中的任务可以分成几个层级：

1. 异常检测：判断当前行为是否偏离正常状态；
2. 故障诊断：识别可能的故障部件或故障模式；
3. 故障预测：判断异常是否持续发展；
4. 维护决策：把诊断结果转换成检修时机和资源安排。

SCADA更常用于前几个层级中的低频状态判断。精确的剩余寿命估计往往需要更丰富的失效历史、部件载荷和维护记录。

## 6. 数据清洗

真实SCADA数据包含大量非平稳和非正常运行状态。常见处理包括：

- 时间戳和采样间隔检查；
- 缺测与重复记录；
- 物理范围检查；
- 状态码过滤；
- 限功率识别；
- 传感器漂移；
- 不同风机之间的变量命名与量纲统一。

Pandit等（2023）把数据收集、特征构造、模型选择、验证和决策视为完整的数据驱动监测流程。诊断性能不能只看训练误差，还要检查异常是否被提前、稳定地识别。

## 7. 与AI方法的接口

SCADA是风电AI研究中很常见的一类工业数据。典型任务包括：

- 功率曲线建模；
- 异常检测；
- 部件温度预测；
- 故障分类；
- 运行状态识别；
- 维护决策辅助。

这类任务与气候风场精细化有明显区别。前者主要面对单机或风场运行数据，时间分辨率更高，控制状态和设备健康信息更丰富；后者主要处理气象场、尺度转换和未来情景迁移。

## 8. 与电气系统的联系

SCADA中包含大量电气变量，因此运行监测也是风资源研究与电气工程之间的一条实际接口。

例如，功率下降可能来自风速下降，也可能来自：

- 限功率指令；
- 变流器状态；
- 发电机温度或故障；
- 电网电压约束；
- 风场级有功功率调度。

判断原因需要同时看气象、控制和电气状态。单独使用风速—功率关系无法覆盖全部运行状态。
