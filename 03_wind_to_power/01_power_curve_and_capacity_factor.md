# 从风速到功率曲线与容量因子

风资源分析进入发电量估计后，需要把风速分布与风机功率曲线联系起来。时间平均、空间平均和非线性映射的处理方式会直接影响结果。

## 1. 风中有多少功率

穿过面积$`A`$的空气流所携带的动能通量可写为

```math
P_{wind}=\frac12\rho A V^3,
```

其中$`\rho`$为空气密度，$`A`$是叶轮扫掠面积，$`V`$为风速。若叶轮半径为$`R`$，则$`A=\pi R^2`$。采用SI单位时，$`\rho`$用kg/m³、$`A`$用m²、$`V`$用m/s，计算得到的$`P_{wind}`$单位为W。

美国能源部的风能资料用这个关系说明可用风功率对风速高度敏感。风速翻倍时，理想可用风功率会增加到原来的8倍。

这个公式描述空气流中可用的功率。风机最终电功率还受到气动效率、控制策略以及机械和电气损失限制。

## 2. Betz极限

理想致动盘理论给出风轮从均匀来流中可提取功率系数的理论上限：

```math
C_p\leq \frac{16}{27}\approx0.593.
```

59.3%对应理想致动盘模型中的空气动力学上限。真实风机还包含传动、发电和控制等环节，而且$`C_p`$会随运行状态变化。

## 3. 真实功率曲线

典型风机功率曲线包含几个关键区域：

- **切入风速**：低于该风速通常不发电；
- **部分负荷区**：功率随风速快速增加；
- **额定功率区**：达到机组设计的额定电功率后，控制系统限制输出，使机组在允许的转速、载荷和电气容量范围内运行；
- **切出风速**：过强风况下停机以保护设备。

DOE资料指出，现代风机常在约3–5 m/s开始发电，在约11–14 m/s达到额定功率，并在约25 m/s附近进入高风停机范围。具体阈值随具体机型和控制策略变化。

## 4. 功率曲线的非线性

设风速是随机变量$`V`$，风机功率曲线是$`P(V)`$。通常有

```math
\mathbb E[P(V)]\neq P(\mathbb E[V]).
```

假设某月一半时间风速2 m/s、一半时间8 m/s，平均风速为5 m/s。如果先把风速平均成5 m/s再进功率曲线，得到的结果不会等于分别计算2 m/s和8 m/s功率后再平均。

时间平均、空间平均与非线性功率映射的先后顺序会直接影响结果。高时间分辨率风速对发电量估计尤其重要。

## 5. 容量因子

容量因子（Capacity Factor, CF）可以理解为某段时间实际发电量与“设备始终以额定功率运行时理论最大发电量”的比值：

```math
CF
=
\frac{E_{actual}}
{P_{rated}\,T}.
```

容量因子是无量纲比值，通常写成百分数。它衡量一段时间内设备相对于额定功率的实际利用程度，与风机把风能转成电能的转换效率属于不同概念；气动转换能力通常用$`C_p`$等量描述。容量因子同时受风资源、机组设计、轮毂高度、停机时间和场内损失等因素影响。NREL资料对这些因素有明确说明。

两个风电场即使年平均风速相似，也可能具有不同CF。

## 6. AEP与CF的关系

年发电量（Annual Energy Production, AEP）和CF直接相关：

```math
AEP=P_{rated}\times8760\times CF
```

式中的8760 h对应普通年的总小时数；闰年为8784 h。若额定功率以MW表示，乘以小时后得到的AEP单位为MWh，较大的项目常进一步用GWh表示。真实评估中还会考虑可利用率、尾流、电气损失、限电、结冰等损失项。

工程实践中经常区分：

- Gross AEP：未扣除全部损失的发电量估计；
- Net AEP：扣除预期损失后的可交付发电量估计。

## 7. 月平均风速用于CF估计的局限

如果数据只有月平均$`u,v`$，先计算

```math
ws=\sqrt{\bar u^2+\bar v^2}
```

再进入功率曲线时会丢失两类信息：

1. 矢量平均会抵消方向变化；
2. 月平均会丢失高频风速分布，而功率曲线是非线性的。

这类结果在本仓库中统一称为“容量因子代理”或“统一口径下的出力指标”，避免与实际物理CF混用。

仅知道平均风速和方差通常仍不足以稳定估算平均功率。风速分布形状、空气密度、风机功率曲线和损失机制都会进入最终结果。
